# matchblox

One terminal console for every AI coding agent you run in tmux. It shows
which agent waits for you, what loads the machine, the state of every git
checkout, and the one safe action that resolves each thing. It works on the
host, over SSH, and from a phone.

![The matchblox console on a demo machine: who waits for you, an answer picked from the agent's own options, the pull requests your sessions drive, usage and the machine, then a night the stoker keeps burning and its score in the morning](assets/replay.svg)

4. [The phone](phone.md): the console as the first screen of an SSH app.

Then, when you need them:
