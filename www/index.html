Light an idea. Keep it burning.

Once, everyone carried a matchbox to light a fire wherever they went. matchblox is the one you carry to every terminal. Run the whole console from your phone: see which coding agent works and which one waits for you, answer it in a line, and follow every pull request it drives from CI to live.

  • Claude Code
  • Codex
  • OpenCode
  • and any agent in tmux

Install

$ curl -fsSL https://matchblox.sh | sh

Linux and macOS · amd64 or arm64 · checksum and provenance checked read the script first ↗

Tell the stoker how to run

Press n before you go and say it in your own words: “keep the priority ones going, and merge them on green.” The stoker starts at once, keeps its own plan, works it through your sessions and logs every step on its card. Merges, releases and deploys ask you, unless you turn their go on.

Every agent in tmux

Start each agent in a tmux session, or press N and matchblox starts one for you. It finds every one, jumps to it with Enter, and answers it with a.

Claude Code, Codex and OpenCode also show how full their context is and which account they run under. Add any other agent by its command in agents.

Keep it burning while you sleep

Press n before you go and give the stoker its order. It carries the order out through your sessions, and each session that fills its context compacts itself and leaves one line on how to go on. In the morning you read the card and carry on.

The stoker is the agent you choose, Claude Code, Codex or OpenCode. matchblox starts it on a tmux server of its own, out of your sessions, and Enter on its tab opens it. It ends a session only with your kills go or your y, and merges, releases and deploys go ahead only on your word. The stoker →

Answer from a peek

Each agent that waits for you comes first. Press a: what it said is there, and when it asks with its own options, a digit answers. An agent at work takes a message too.

Every pull request, CI to live

The pull requests your sessions drive, each on one track: CI, a conflict, a review, the merge and the deploy. One that waits for you merges after a typed y.

Start, rename, kill

N starts an agent where you work, with its first message, in a tmux session of its own: the session and the agent share one name, and r renames both. x ends a session after a typed y. Its worktree and its transcript stay.

Usage and the machine at a glance

What /usage says for every account, CPU, memory and disk, and the stoker's night, in the rows the list leaves free. Any fix shows its exact command first.
